# Weather Intelligence Application

An AI-generated Weather Intelligence Application built with React, Vite, Tailwind CSS, and Open-Meteo API.

## Features
- City weather search (Current weather, 7-day forecast, temperature charts, and smart advice cards)
- Real-time weather data via Open-Meteo Geocoding & Forecast APIs
- Responsive layout with error handling for invalid city searches

## Deployment Instructions

### 1. Google AI Studio to GitHub
- Generated in Google AI Studio App Build using Open-Meteo API prompts.
- Connected directly to GitHub repository `weather-intelligence-app`.

### 2. Cloudflare Pages Deployment
- Connected GitHub repository to Cloudflare Pages.
- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Live URL:** `https://weather-intelligence-app-3a3.pages.dev`
